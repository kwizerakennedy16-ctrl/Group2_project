# Ndejje Campus Connect

A Kotlin-based mobile app built with Jetpack Compose and MVVM architecture. The app centralizes campus news, timetables, maps, and resources into one platform, helping students, staff, and administrators stay informed and connected.

## 📂 Features
- **Onboarding & Login** – secure identity management  
- **Campus News Feed** – dynamic announcements and events  
- **Digital Campus Map** – navigation for lecture halls and offices  
- **Academic Dashboard** – timetables, exam schedules, deadlines  
- **Resources & Directory** – searchable contacts and student guides  

---

## 🛠 Tech Stack
- **Language**: Kotlin  
- **UI Framework**: Jetpack Compose (Material 3)  
- **Architecture**: MVVM  
- **Persistence**: Room Database / Retrofit API  
- **Testing**: Unit & integration tests
